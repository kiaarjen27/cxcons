One Folder Rule for HRDC Supporting Documents

Claims fail in email threads. One controlled folder per programme run is operational hygiene.

If everyone has a copy, no one has the file

Shared inboxes and personal drives create competing versions of attendance and invoices. When a claim query arrives, the organisation spends days reconstructing what should have been one path.

Folder minimum

  • Outline / programme structure actually delivered
  • Attendance (complete, dated, identifiable)
  • Invoice and payment proof trail
  • Trainer type note if relevant
  • Exception notes (withdrawals, short hours, replacements)

Naming

Use programme + date + company in the folder name so finance can find it months later. Close the folder within seven days of the last session day — while memory is still accurate.
