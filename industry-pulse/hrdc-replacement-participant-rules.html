Replacement Participants: Handle Before Class Starts

Substitutions are normal. Undocumented substitutions become attendance disputes.

Name changes need a controlled process

If someone else attends, the record must show who was present — not only who was originally nominated. Claim and certificate files both depend on that truth.

Control substitutions

  • Set a cutoff time for name changes (for example 24–48 hours before class)
  • Issue an updated attendance pre-list to the provider
  • Require manager confirmation for the replacement
  • Apply the same evidence standard to the person who actually sat in class

What goes wrong when you skip this

  • Invoice headcount matches nominations, not attendance
  • Certificates printed for people who never attended
  • Claim queries about identity and completion
