Keep a Provider Communication Log

Verbal changes become invisible. Short written confirmations protect both employer and provider.

Scope changes need a trail

Headcount drops, timing changes, and outline tweaks should be acknowledged in writing before delivery. Memory is a weak contract.

Log the essentials

  • Confirmed dates and hours
  • Final headcount assumption
  • Outline version
  • Commercial inclusions / exclusions

Minimum viable log

A shared email thread or one page in the programme folder is enough. The point is a recoverable record, not bureaucracy for its own sake.
